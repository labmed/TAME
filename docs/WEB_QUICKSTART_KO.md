# tametools 0.4.0 공통 작업실: 사용자 시험 안내

모든 자료는 같은 작업실에서 분석합니다. NHANES는 **공개 예제 불러오기**에 있는 시험용 자료 중 하나입니다. 별도 시작 화면이나 NHANES 분석 마법사는 없습니다.

## 실행과 자료 선택

1. 개인용 브라우저 ZIP을 전체 압축 해제한 뒤 Windows에서는 `Start_Chrome.cmd`, macOS/Linux에서는 `bash Start_Chrome.sh`를 실행합니다. Python 3.10–3.13 64비트와 Chrome이 필요합니다. 첫 실행에는 패키지 설치용 인터넷 연결이 필요합니다.
2. 상단 **공개 예제 불러오기 → Kenya 참고인 자료 불러오기**를 누릅니다. 배포본에 포함된 533명·6종 임상화학 자료로 다운로드 대기 없이 시작할 수 있습니다. 개인별 연령은 제공되지 않습니다. 원자료 Sex 코드는 보존하고, 선언된 매핑으로 만든 분석용 Sex_standard와 LOG를 함께 제공합니다.
3. 또는 **NHANES 불러오기**에서 2017–2018 / 2021–2023을 선택합니다. 공식 DEMO/BIOPRO 자료와 설명서를 받고, 출처·해시·단위·층·집락·가중치를 포함한 TAME로 엽니다. 기존 캐시가 있으면 재사용합니다.
4. 본인 자료는 **파일 열기**로 Excel 또는 TAME를 엽니다. 일반 Excel은 먼저 시트별 구조와 경고를 검토하고 변환합니다.

## 공통 기능을 시험하는 순서

1. **데이터**에서 검사명, 단위, 실제 값을 확인합니다. 헤더를 누르면 **속성·플러그인**에서 태그·열 설명·단위·PIVOT_CONTEXT를 확인할 수 있습니다. 태그를 포함한 전체 헤더와 반올림 전 값은 마우스를 올리면 표시됩니다.
2. **1. 데이터 상태 확인**, **2. 검증·표준화 확인**을 실행합니다. 3–5번 표준화·부등호 정책은 필요한 자료에만 적용합니다. 모든 번호를 의무적으로 실행하는 절차가 아닙니다.
3. **6. 탐색 분석 실행**을 누릅니다. 결과가 새 TAME로 작업 이력에 추가됩니다. 상단 **작업 입력**은 원자료를 계속 가리킵니다.
4. 결과표를 보고 있는 상태에서 **7. EP28 참고구간**을 누릅니다. 설정 패널의 입력 파일이 원자료인지 확인합니다. 검사·방법·이상치 판정/조치·분할·신뢰수준을 설정하고 해석 주의사항을 확인한 뒤 계산합니다. Kenya 기본값은 6개 검사, 성별 분할, 비모수, Tukey 표시만입니다.
5. 결과에서 단위·유효 표본 수·후보 참고구간·양 끝의 신뢰구간·상태를 확인합니다. 아래 상세 결과에는 입력 제외 사유, 집단 배정, 이상치, 분할 평가가 있습니다. 소표본 집단은 **산출 안 됨**과 사유를 함께 표시합니다. 모수법의 음수 하한을 임의로 0으로 바꾸지 않습니다.
6. **Word 보고서 저장**, **전체 보고서 ZIP 저장**을 시험합니다. ZIP에는 입력 TAME, 결과 TAME, 유효 입력 스냅샷, 계산 설정, 상세 표와 보고서가 들어 있습니다.
7. **TAME 저장 / Excel 저장**은 현재 보고 있는 항목을 저장합니다. 원자료를 저장하려면 작업 이력에서 입력 자료를 선택하세요. 화면 반올림은 저장한 수치에 적용하지 않습니다. 저장한 TAME를 다시 열어 META와 LOG를 확인하세요.

EDA 결과를 열어도 참고구간은 고정된 **작업 입력**에 실행됩니다. 표준화나 전처리로 새 입력 자료를 만들면 작업 입력이 해당 자료로 갱신됩니다. 이력에서 다른 입력 자료를 선택하거나 상단 선택 상자로 분석 대상을 바꿀 수 있습니다. 분석 결과표는 입력 선택 목록에 들어가지 않습니다.

## NHANES로 추가 확인할 내용

- 일반 **탐색 분석**은 비가중 요약입니다. 모집단 추정치로 해석하지 않습니다.
- **저장된 분석 실행**은 META의 `ANALYSIS_PLAN`을 적용합니다. 기본값은 ALT·크레아티닌·알부민, 20세 이상, 남녀 및 전체 집단이며 해당 시기의 조사 가중치·층·집락을 사용합니다. 결과는 공통 분석결과 화면에 나타납니다. 분석계획은 메타 탭에서 확인할 수 있습니다.
- 2017–2018년 ALT에는 `<3`와 공개 대체값 바인딩이 있습니다. EP28 기본 검열값 정책은 해당 값이 있으면 중단합니다. 목적에 맞게 **공개 대체값 사용**, **계산에서 제외** 등을 명시적으로 선택합니다. 두 정책의 결과는 같은 의미가 아닙니다.
- 2021–2023년의 선택된 검사에는 검출한계 표시 열이 없습니다. 공개값만으로 미만값을 역추정하지 않습니다.
- NHANES는 일반 인구 조사이므로 건강한 참고인 집단이 아닙니다. EP28 결과는 소프트웨어 시험용 후보 구간입니다. 조사 가중 참고구간이 아닙니다. 연령 80은 80세 이상이므로 정확한 80세로 분할하지 않습니다.

## 화면과 저장

- 실행 중에는 상단에 진행 표시가 나타나며 중복 실행을 막습니다. 오류는 같은 위치에 표시하고 설정은 유지하므로 수정 후 재시도할 수 있습니다.
- 그리드는 미리보기 최대 5,000행을 표시합니다. 전체 행은 메모리와 저장 파일에 유지됩니다. 일반 결과표는 50행씩 넘겨 보며, EP28 요약은 첫 100행을 표시합니다.
- 입력 열의 태그와 원문은 보존하며, 화면에서 숫자는 최대 소수 4자리로 표시합니다. 식별자·문자열에는 숫자 표시 규칙을 적용하지 않습니다.
- 부등호 정책은 **분석에서 제외** 또는 **경계값으로 분석**을 선택합니다. 원문과 행을 삭제하는 기능이 아닙니다. EDA는 `SETTINGS.CRR`, EP28은 별도 `CENSOR_POLICY`를 사용합니다.
- 작업실 이력은 브라우저 메모리에 있습니다. 새로고침·종료 전 결과를 저장하세요. 진행 중인 NHANES 다운로드는 같은 서버에서 다시 열 때 이어서 확인할 수 있습니다. 서버를 종료하면 임시 보고서는 사라집니다.

## 재현 검증

보고서 ZIP의 `analysis_input.tame`를 공통 작업실에서 열면 동일한 EP28 설정을 다시 사용할 수 있습니다. 다음 Python 코드로 배포본의 엔진에서 그대로 재계산할 수도 있습니다.

```python
from tametools.io import read_tame
from tametools.plugin_base import run_plugin
source = read_tame("analysis_input.tame")
result = run_plugin(source, "RI_EP28", source.meta, "RI_EP28", {})
print(result.tables["reference_intervals"].to_string(index=False))
```

## 구성요소 오류

오류에 누락된 패키지와 실행 중인 Python 경로가 표시됩니다. 소스 실행 환경은 저장소 루트에서 오류에 표시된 Python으로 다음 설치를 실행하고 서버를 다시 시작합니다.

```bash
python -m pip install -e "./tametools[analysis,nhanes,web,report]"
```

브라우저 배포본은 앱을 종료한 뒤 `python scripts/start_tametools_browser.py --repair`로 전용 환경을 복구할 수 있습니다. 기존 개인 Python 환경과 배포본의 전용 환경은 별개입니다.

## 서로 다른 성별 코드가 병합된 자료 시험

숫자 `1`만으로 성별을 추정할 수 없습니다. **출처를 식별하는 열이 남아 있으면** 병합 후에도 각 자료의 코드표를 별도로 지정할 수 있습니다.

1. `web/backend/examples/sex_coding_sources.xlsx`를 열고 `A_0_1`, `B_1_2` 두 시트를 선택하여 병합합니다. 이미 병합한 `sex_coding_merged.tame`를 열어도 됩니다. 이 6행은 코드 연결을 시험하는 인공 예제이며 임상 분석이나 임상 결과용 자료가 아닙니다.
2. **3. 성별값 표준화**를 누릅니다. 원 성별 열 `Sex`, 출처 열 `시트명`을 선택하고 **출처별 코드 확인**을 누릅니다.
3. A_0_1의 `0 → female`, `1 → male`; B_1_2의 `1 → female`, `2 → male`을 지정합니다. 코드의 의미는 예제에 정한 값입니다. 실제 자료는 해당 코드 설명서를 따라야 합니다.
4. 미리보기에서 **남성 3행, 여성 3행**을 확인합니다. 미지정 코드나 출처 결측이 있으면 적용할 수 없습니다. 확인란을 선택하고 **표준 성별 열 생성**을 누릅니다.
5. 원 `Sex`·`시트명`·6행이 남고, 새 `Sex_standard`가 분석용 SEX 열이 되었는지 확인합니다. TAME 또는 Excel로 저장한 뒤 다시 열어 META의 `SEX_NORMALIZATION`과 LOG의 `NORMALIZE_SEX_BY_SOURCE`를 확인합니다. `sex_coding_expected.csv`와 행별로 대조할 수 있습니다.
6. 기존 출처 열이 없는 서로 다른 숫자 코딩은 자동 분리할 수 없습니다. 원자료에서 출처를 복원한 뒤 설정하세요. 한 가지 코드 체계를 쓰는 자료만 **출처 구분 없음 · 공통 규칙**을 사용합니다.

규칙은 원 성별·출처·결과 열의 `COLUMN.ID`로 저장합니다. 지원되는 열 이름 변경과 열 순서 변경 후에도 다음 코드로 명시적으로 재실행할 수 있습니다. 파일을 읽는 것만으로 규칙을 자동 실행하지 않습니다. 기존 원 열을 참조하는 사용자 작성 `ANALYSIS_PLAN`의 ID는 따로 검토해야 하며 EP28의 성별 입력은 표준 열로 연결됩니다.

```python
from tametools.io import read_tame
from tametools.sex_normalization import normalize_sex_by_source
source = read_tame('saved.sex_std.tame')
replayed = normalize_sex_by_source(source)
```

## 개선된 분석 결과 확인

- EP28 차트는 검사·단위·집단별 하한–상한과 각 한계의 CI를 표시합니다. AST·GGT·Creatinine 차트에 마우스를 올려 해당 표의 값과 대조하세요.
- 결과 위에 실제 적용한 방법, 포함률, CI, 이상치 조치·경고 비율, 검열값 정책, 분할, 유효 n 범위를 표시합니다. 공통 해석 주의사항은 한 번 표시하고 행별 사유를 구분합니다. 기본 이상치 경고 비율은 2%이며 설정에서 변경할 수 있습니다.
- 큰 감사표는 처음 화면 응답에 전체 행을 넣지 않습니다. 상세 영역에서 **50행 미리보기 / 다음 50행 / 전체 CSV 저장**을 사용합니다. ZIP과 CSV에는 전체 기록이 있습니다. CSV는 `encoding='utf-8-sig'`로 읽으면 BOM도 제거됩니다.
- **10. 저장된 분석 실행**과 별도 **저장된 분석 실행**은 같은 ANALYSIS_PLAN을 적용합니다. 조사 결과는 가중 평균·95% CI·유효 n을 우선 표시하고 가중치·층·PSU·엔진 정보는 상세 열로 확인합니다.

작은 p값처럼 `4.2e-28`로 표시되는 유한한 지수 표기도 NUM으로 검증하고 분석합니다. NaN·무한대와 잘못된 지수 표기는 숫자로 인정하지 않습니다.

## 분석 이력 검토

`분석 이력` 탭에서 단계별 입력·출력 건수, 출처별 코드표, 설정과 경고를 확인합니다. `현재 값으로 기록 검증`은 편집 중인 데이터·META를 기록된 값과 비교합니다. `전체 이력 JSON 저장`과 TAME/Excel 재열기로 이력이 함께 전달되는지 확인할 수 있습니다. 실패한 분석은 상단의 `실패 실행 기록 저장`으로 검토합니다. 세부 범위와 CLI 사용법은 [분석 이력 안내](ANALYSIS_LOG_GUIDE_KO.md)를 참고하세요.
